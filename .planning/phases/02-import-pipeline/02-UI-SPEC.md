## Color

Inherited from Phase 1. Dark mode only. All values are dark-mode resolved from globals.css.

| Role | shadcn Token | Resolved (dark) | Usage |
|------|-------------|-----------------|-------|
| Dominant (60%) | `background` | oklch(0.145 0 0) ≈ zinc-950 | Page background, root surface |
| Secondary (30%) | `card` | oklch(0.205 0 0) ≈ zinc-900 | Dashboard cards, error card, session table container |
| Accent (10%) | `primary` | oklch(0.554 0.252 296) = violet-600 #7c3aed | Accent elements only (see reserved-for list) |
| Destructive | `destructive` | oklch(0.704 0.191 22.216) ≈ red-500 | Destructive actions only |
| Border | `border` | oklch(1 0 0 / 10%) | Card borders, table row dividers, input outlines |
| Muted text | `muted-foreground` | oklch(0.708 0 0) ≈ zinc-400 | Helper text, session row secondary info, empty states |
| Warning surface | amber-950 (#1c1400) | — | Attribution error card background (inline tint, not a shadcn token) |
| Warning border | amber-700 (#b45309) | — | Attribution error card left border accent |
| Warning text | amber-400 (#fbbf24) | — | Attribution error card icon and count label |

Accent reserved for:
1. "Start import" button background (admin-only, default state)
2. Active/current nav indicator (inherited from Phase 1)
3. Keyboard focus rings on all interactive elements (via `--ring` token)
4. "Save" / "Confirm" actions within the attribution slot editor

Warning colour (amber) reserved for:
1. Attribution error card only — sessions where initials string was unparseable (IMPORT-08)
2. Never used for decorative elements or standard UI states

Never use accent or warning colours for headings, body text, or decorative elements.

Source: 01-UI-SPEC.md color contract extended; warning amber from standard semantic convention (default)

## Layout Contract

### Dashboard Page `/dashboard` — Phase 2 Additions

The existing dashboard layout (max-width 640px, single-column, horizontally centered) is extended with two new sections inserted below the `ImportTriggerCard` and above the sign-out button. Section order (top to bottom):

1. Signed-in user block (Phase 1, unchanged)
2. Separator (Phase 1, unchanged)
3. Import trigger card — extended with progress feedback (Phase 2 replaces stub)
4. Separator (new, md token gap above and below)
5. Attribution error card — conditional, only visible when ≥1 session has a parse error (Phase 2 new)
6. Separator (new, md token gap, only rendered when attribution card is shown)
7. Session date entry table (Phase 2 new)
8. Sign-out button (Phase 1, pushed down)

### Import Trigger Card — Extended States

The existing `ImportTriggerCard` is replaced with a version that shows real progress. The card visual structure is preserved; new elements added inside `CardContent`:

- **Progress bar** (shadcn Progress): shown only during active import, full-width, accent colour fill, 8px height
- **Status line**: 14px label, muted-foreground colour, e.g. "Fetching playlist 3 of 31…"
- **Completion summary**: 14px label, shown after import completes — "31 sessions imported, 496 tracks stored."
- **Error summary** (if any failures): destructive colour text, 14px — "2 playlists could not be fetched. Check the error card below."

### Attribution Error Card

Visible only when ≥1 session has an unparseable initials string (IMPORT-08).

Layout: shadcn Alert component with `variant="default"` and custom amber left-border override.

```
[!] 3 sessions need manual attribution
    ─────────────────────────────────────────
    Session 07 — "Desert Island Discs"
      Tracks 1–4:  [Mark Wright ▼]
      Tracks 5–8:  [Jack Groves ▼]
      Tracks 9–12: [Jon Slade   ▼]
      Tracks 13–16:[Iwan Thomas ▼]
      [Save attribution]
    ─────────────────────────────────────────
    Session 14 — "One Hit Wonders"
      ... (same slot layout)
```

- Card heading: "N sessions need manual attribution" (Heading role, 20px/600)
- Card subtext: "The descriptions below did not contain a recognisable initials string. Assign contributor order manually." (Body role, 16px/400, muted-foreground)
- Each errored session: its theme as a row heading (Label role, 14px/400, semibold)
- Each slot row: "Tracks 1–4:" label (Label role, 14px/400, muted-foreground) + Select dropdown (contributor name)
- Save button per session: `variant="default"` (violet accent), label "Save attribution", 100% width of the session sub-card
- After save: badge changes from amber "Unassigned" to green-tinted "Assigned", row collapses

### Session Date Entry Table

Location: below attribution error card (or below import card if no errors), above sign-out.

Container: `Card` with `CardHeader` ("Session dates") and `CardContent` holding a `Table`.

Table structure:
- No horizontal scroll — table fits within 640px column
- Column widths: `#` (40px fixed), `Theme` (flex grow), `Date` (160px fixed)
- Column headers: "No.", "Theme", "Date" — Label role (14px/400), muted-foreground
- 31 rows, one per session, sorted by session number ascending
- Session number: Label role (14px/400), muted-foreground, right-aligned in 40px column
- Theme: Body role (16px/400), truncated with ellipsis if overflows
- Date: native `<input type="date">` inside each cell — no custom datepicker

Date input behaviour:
- Unsaved state: standard input appearance, `border` token colour
- Focused: `ring-2 ring-violet-500` (accent focus ring, consistent with Phase 1 global focus rule)
- Saved (blur or Enter): input briefly shows green tick icon (Lucide `Check`, 14px, green-500) for 1.5s then returns to normal — no toast for individual date saves to avoid noise
- Saving (pending): input briefly disabled with `opacity-50 cursor-wait` while PATCH request in flight
- Error (PATCH failed): input border turns destructive colour, Lucide `AlertCircle` icon appears inline, tooltip "Could not save date — try again"

Empty date cells: placeholder text "Pick a date" (native placeholder attribute).

## Interaction States

### Import Trigger Card — Full State Machine

| State | Visual |
|-------|--------|
| Default (no import running, no history) | Button enabled (violet), no progress bar, no status text |
| Running | Button disabled (muted), label "Importing…", spinner icon; progress bar visible (accent fill, animated); status line below bar |
| Success | Button re-enabled; progress bar hidden; completion summary line visible (14px, muted-foreground); toast "Import complete" |
| Success with errors | Button re-enabled; completion summary with error note (destructive text); "see below" text links attention to attribution card |
| Error (hard failure) | Button re-enabled; progress bar hidden; error summary (destructive text, 14px); toast fired |

### Attribution Slot Select

| State | Visual |
|-------|--------|
| Default (unassigned) | Select shows "Select person…" placeholder, amber badge "Unassigned" |
| Open | Radix Select dropdown, standard shadcn popover style |
| Assigned (unsaved) | Select shows person name, save button enabled |
| Saving | Save button disabled, label "Saving…", spinner icon |
| Saved | Badge changes to "Assigned" (green-500 text, green-900 bg at dark), row collapses after 2s |
| Save error | Toast fires, badge stays "Unassigned", save button re-enabled |

### Session Date Input

| State | Visual |
|-------|--------|
| Default (no date) | Native date input, placeholder "Pick a date", border token colour |
| Focused | Ring-2 violet-500, 2px offset (inherits global focus ring rule) |
| Saving (PATCH in flight) | opacity-50, cursor-wait, input disabled |
| Saved | Green check icon (Lucide Check, 14px) appears for 1.5s, then disappears |
| Error | Destructive border colour, AlertCircle icon inline, tooltip "Could not save date — try again" |

### Global Focus Ring (unchanged from Phase 1)

All interactive elements: `outline-2 outline-offset-2` with `--ring` token set to violet-600. Applied via `@layer base * { @apply outline-ring/50 }` in globals.css.
