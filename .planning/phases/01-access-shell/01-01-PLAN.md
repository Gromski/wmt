## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → local machine | npm install pulls third-party code from the public registry into `node_modules`. The packages execute on the developer's machine and ship into production. |
| Spotify Dashboard → developer | Out-of-band human handoff of Client ID + Client Secret. Secrets must land in `.env.local` only — never echoed in chat, never committed. |
| `.env.local` file → process.env | Secrets at rest on the dev machine. `.gitignore` is the only thing keeping them out of source control. |
