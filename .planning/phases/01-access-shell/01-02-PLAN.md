        ```
        await authClient.signIn.email(

          {
            onRequest:  () => setIsPending(true),
            onSuccess:  () => router.push("/dashboard"),
            onError:    (ctx) => { setIsPending(false); toast.error("Sign-in failed. Check your email and password and try again."); }
          }
        );
        ```
      - If `mode === 'sign-up'`:
        ```
        await authClient.signUp.email(
          { email, password, name, callbackURL: "/dashboard" },
          {
            onRequest:  () => setIsPending(true),
            onSuccess:  () => router.push("/dashboard"),
            onError:    (ctx) => { setIsPending(false); toast.error(ctx.error.message ?? "Sign-up failed. Please try again."); }
          }
        );
        ```
