  "<Name>'s <ordinal> track: <Artist> - <Title> <url>"

where <ordinal> is first/second/third/fourth/last (or 1st/2nd/3rd/4th) — this pins the track to that person's round-robin slot. Genuine EXTRA tracks (not one of the 4 grid picks) use a non-ordinal descriptor like "bonus" and are appended at the session end. Multiple fallbacks per description are separated by " / ". Names map: Mark→MW, Jack→JG, Jon/Jonny→JS, Iwan→IT.
