<objective>
Complete the browse surface by making it interactive: add the three-mode view toggle (grid / table /
timeline) with URL persistence, and the single client-side search box that filters across theme,
person, and artist. This extends the ArchiveClient island created in Plan 02 (which already ships the
grid) — it does not rewrite it. After this plan a user can toggle views, share a ?view= URL, and
filter the archive instantly, making BROWSE-04 and BROWSE-05 true.

Purpose: BROWSE-04 (timeline) and BROWSE-05 (search) are the interactive layer over the payload the
RSC already pre-loads. Search runs entirely client-side over the ~100KB payload (D-14) — no API route,
no round-trips. The dataset is tiny (31 sessions), so a useMemo filter and local sort state suffice.

Output: extended ArchiveClient (toggle + search + table + no-results state) and a presentational
SessionTimeline component.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public browser → ArchiveClient | Unauthenticated client island; search input is user-controlled text |
| URL ?view= query param → view state | User-controlled query value drives which view renders |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-08 | Injection | search input | mitigate | Query used only as a JS `.toLowerCase().includes()` predicate over an in-memory array and rendered as React text (auto-escaped); never interpolated into HTML, SQL, or a URL; no dangerouslySetInnerHTML |
| T-03-09 | Tampering | ?view= param | mitigate | View value narrowed to the union "grid"|"table"|"timeline" with a default fallback to "grid"; any other value falls back to grid, no code path executes attacker-controlled strings |
| T-03-10 | Information Disclosure | client search payload | accept | Payload is the same public archive data already rendered on the page (D-14); no additional sensitive fields exposed by shipping it to the client |
| T-03-SC | Tampering | npm installs | accept | Zero new packages this phase; legitimacy gate not applicable |
</threat_model>
