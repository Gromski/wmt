> Visual and interaction contract for Phase 3: Archive Browsing.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> This phase is the public, read-only browse layer over Phase 2 data. It MUST
> inherit the Phase 1 design system (dark-zinc + violet primary, shadcn v4

## Spacing Scale

Inherited from Phase 1. Declared values (must be multiples of 4):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Icon-to-label gaps, chip padding, link-icon button inner padding |
| sm | 8px | Table cell vertical padding, chip-to-text gap, view-toggle segment gap |
| md | 16px | Card padding, track-row vertical padding, search box padding, grid gap (mobile) |
| lg | 24px | Card grid gap (desktop), section spacing, detail-header block spacing |
| xl | 32px | Layout column gaps, gap between search+toggle bar and results |
| 2xl | 48px | Detail-header vertical padding, top of archive page |
| 3xl | 64px | Page-level top/bottom padding |

Exceptions: Link-icon buttons and the timeline node dots must present a **minimum 44px touch target** (mobile accessibility) even when the visible icon is 16–20px — pad the hit area, not the glyph.

## Typography

Inherited from Phase 1. No new roles introduced.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 14px | 400 (regular) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Display | 28px | 600 (semibold) | 1.2 |

Font family: Inter for all roles.

Phase 3 role assignments:
- **Display (28/600)** — session-detail page title: the session theme (`/sessions/[sessionNumber]`). One per detail page.
- **Heading (20/600)** — the `/sessions` archive page title ("Sessions"); session-card theme text.
- **Body (16/400)** — track title, session-card metadata, table cells, session description text, search input text.
- **Label (14/400)** — contributor chip initials, artist / album / year secondary text, table column headers, "Date TBD" placeholder, view-toggle segment labels, "attribution pending" note, empty-state body.

Secondary track metadata (artist · album · year) uses Label size in `muted-foreground`; the track **title** uses Body size in `foreground` to establish clear row hierarchy.

## Color

Inherited dark-zinc + violet system (all values dark-mode resolved from `app/globals.css`). The browse UI adds a **fixed four-person contributor colour map** — the only net-new colour tokens in this phase.

### Base palette (inherited — do not redefine)

| Role | shadcn Token | Resolved (dark) | Usage |
|------|-------------|-----------------|-------|
| Dominant (60%) | `background` | zinc-950 (oklch 0.145) | Page background, root surface for `/sessions` and detail |
| Secondary (30%) | `card` | zinc-900 (oklch 0.205) | Session cards, table container, detail header block, search-bar surface, timeline rail cards |
| Accent (10%) | `primary` → violet | violet-600 (oklch 0.554 0.252 296) | Active view-toggle segment, focus rings, active/hover session-card border, hovered timeline node |
| Destructive | `destructive` | red (oklch 0.704 0.191 22) | Not used in Phase 3 (read-only surface — no destructive actions) |
| Border | `border` | zinc-800 (white/10%) | Card borders, table row dividers, search-box outline, section separators |
| Muted text | `muted-foreground` | zinc-400 (oklch 0.708) | Secondary metadata, "Date TBD", "attribution pending", empty-state body, artist/album/year |

Accent (violet) reserved for:
1. Active segment of the view-mode toggle (grid / table / timeline)
2. Keyboard focus rings on all interactive elements (search box, toggle, links, card, table sort headers)
3. Session-card hover/focus border highlight
4. Timeline node dot on hover/focus

Never use accent for decorative fills, headings, body text, or the contributor chips (those have their own map below).

### Contributor colour map (NEW — locked, reusable in Phase 4)

Each of the four contributors gets one fixed identity colour, consistent everywhere (track-row chips, search/filter pills, and Phase 4 analytics). Define these as named CSS variables in `app/globals.css` under `.dark` so Phase 4 reuses them without redefinition. All four meet ≥4.5:1 contrast for their near-white text against the chip fill, and the chip fill is distinguishable against zinc-900 cards and zinc-950 background.

| Contributor | Initials | Token name | Chip fill (dark) | Foreground | Lucide/no icon |
|-------------|----------|------------|------------------|------------|----------------|
| Mark Wright | MW | `--contributor-mw` | violet-600 (oklch 0.554 0.252 296) | zinc-50 (`oklch 0.985 0 0`) | initials only |
| Jack Groves | JG | `--contributor-jg` | blue-600 (oklch 0.546 0.215 262) | zinc-50 | initials only |
| Jon Slade | JS | `--contributor-js` | amber-500 (oklch 0.769 0.156 70) | zinc-950 (`oklch 0.145 0 0`) | initials only |
| Iwan Thomas | IT | `--contributor-it` | emerald-600 (oklch 0.596 0.145 163) | zinc-50 | initials only |

Contrast note: amber is a light fill, so JS uses **dark (zinc-950) initials** for readable contrast; the other three use near-white (zinc-50) initials. The map is exposed as a single source of truth (e.g. a `CONTRIBUTOR_COLORS` const keyed by initials plus the CSS variables) so chips, filter pills, and Phase 4 charts stay in lockstep.

MW deliberately shares the violet family with the app primary — this is intentional identity overlap, not accent misuse; chips are a data-encoding, not an interactive-accent, use.

Source: user decision relayed via coordinator (Option A, palette assignment delegated to Claude). Base palette from `app/globals.css` + Phase 1 `01-UI-SPEC.md`.

## Layout Contract

### Global Header (inherited)
Unchanged from Phase 1. The app-name link in the header points to `/sessions`. No auth gate on browse routes.

### `/` → `/sessions` redirect
`app/page.tsx` performs a server redirect to `/sessions`. No landing UI rendered.

### Archive page `/sessions`
- Single centered column, max-width 1120px, horizontal padding 16px (mobile) / 24px (desktop).
- Top padding 48px (2xl); page title "Sessions" (Heading, 20/600) at top-left.
- **Controls bar** below the title (32px / xl gap from results): left = search box (grows to fill), right = view-mode toggle (3 segments). On mobile these stack vertically with 16px (md) gap; search on top.
  - **Search box**: full-width on mobile, min-width 280px on desktop; `Search` icon left-inset; `card` surface, `border` outline; violet focus ring. Placeholder copy per Copywriting Contract. Filters instantly on input (client-side, no submit button).
  - **View-mode toggle**: three segmented buttons (grid / table / timeline), icon + Label. Active segment = violet fill + zinc-50 text; inactive = ghost, `muted-foreground`. Grid is default on load. Selected mode persists in URL query (`?view=`) so it is shareable/back-button-safe.
- **Grid mode (default)**: responsive card grid. 1 column (mobile <640px), 2 columns (≥640px), 3 columns (≥1024px). Gap 24px (lg). Newest session first (descending sessionNumber).
- **Table mode**: shadcn Table inside a `card`-surface container. Columns: No / Theme / Date / Contributors. Sortable by clicking header (violet `ArrowUpDown` indicator on active sort). Default sort: No descending (newest first). Row hover = subtle `secondary`/muted background; whole row links to detail.
- **Timeline mode**: single vertical rail. Dated sessions ordered by date descending (newest at top); **undated sessions fall to the bottom, ordered by sessionNumber descending** (they are never hidden — D-12). Each node: a dot on the rail (violet on hover/focus, `border` colour at rest), a small `card` with session number, theme, date/"Date TBD", and the four contributor chips. Optional year-group `Separator` labels between calendar years.

### Session card (grid mode)
- `card` surface, `border` outline, `rounded-lg` (radius token), padding 16px (md).
- Top line: session number as a small `muted-foreground` Label (e.g. "Session 31"); theme as Heading (20/600) `foreground`.
- Second line: date (Body, `foreground`) or "Date TBD" (Label, `muted-foreground`).
- Bottom: row of four contributor chips (Avatar, coloured per map, 24px), 4px gap; tooltip on each = full name.
- Whole card is a link to `/sessions/[sessionNumber]`. Hover/focus: border shifts to violet, subtle lift (no colour-fill change). Focus ring visible for keyboard nav.

### Session detail `/sessions/[sessionNumber]`
- Single centered column, max-width 880px, top padding 48px (2xl), horizontal padding 16/24px.
- **Back link**: `ArrowLeft` + "All sessions" (ghost Button / link) at top, returns to `/sessions`.
- **Detail header block** (`card` surface, padding 24px lg):
  - Session number (Label, `muted-foreground`) + theme (Display, 28/600) as the page title.
  - Date (Body) or "Date TBD" (Label, `muted-foreground`).
  - Four contributor chips (Avatar per map, 24px) with full-name tooltips.
  - Raw playlist `description` text rendered as Body in `muted-foreground`, preserving line breaks, in a subtly-inset block.
- `Separator` between header and track list.
- **Track list**: single play-order list, positions 1–16, one row per track. Row layout (left → right):
  1. Position number (Label, `muted-foreground`, tabular, fixed width ~24px).
  2. Contributor chip (Avatar, coloured per map, 20–24px) — the chooser for this track via round-robin `initials[(position-1) % 4]`. **Omitted entirely for unattributed sessions** (D-09).
  3. Track title (Body, `foreground`, primary) with artist · album · year beneath or inline (Label, `muted-foreground`).
  4. Link-icon buttons, right-aligned: Apple Music (`Music`/`ExternalLink`) and/or YouTube (`Youtube`). Ghost icon buttons, 44px touch target, open in new tab (`target="_blank" rel="noopener noreferrer"`), Tooltip labels.
  - Row vertical padding 16px (md); `border`-colour divider between rows (Table or divided list — either is acceptable, keep row height consistent).
- **Unattributed sessions**: render the play-order list with **no contributor chips**, and a single subtle "attribution pending" note (Label, `muted-foreground`, with an optional `Badge` outline variant) directly under the header. Session remains fully viewable.

### Track link edge cases
- Track with `appleId` only → Apple Music icon button only.
- Track with a YouTube fallback URL only → YouTube icon button only.
- Track with both → both buttons (Apple first, YouTube second).
- Track with **neither** → render **no icon button at all** and no empty placeholder (D-10e). The row still shows title/artist/album/year. Do not render a disabled or dead button.
- Apple Music deep-link format: `https://music.apple.com/{storefront}/song/{appleId}` — default storefront `gb` (the group is UK-based; Claude's-discretion per D-10b).

## Interaction States

### View-mode toggle
| State | Appearance |
|-------|-----------|
| Active segment | Violet (`primary`) fill, zinc-50 label + icon |
| Inactive segment | Ghost, `muted-foreground` label + icon |
| Hover (inactive) | `secondary`/muted background, `foreground` label |
| Focus | Violet 2px focus ring, 2px offset |

### Search box
| State | Appearance |
|-------|-----------|
| Default | `card` surface, `border` outline, `muted-foreground` placeholder, `Search` icon left |
| Focus | Violet focus ring; results filter live as the user types |
| Has query, matches | Results filtered instantly; a "Clear search" affordance appears |
| Has query, no matches | Results area shows no-search-results state (heading + body + Clear search) |

### Session card
| State | Appearance |
|-------|-----------|
| Default | `card` surface, `border` outline |
| Hover / focus | Border shifts to violet, subtle elevation; contributor tooltips available |
| Keyboard focus | Visible violet focus ring on the card link |

### Track-row link-icon buttons
| State | Appearance |
|-------|-----------|
| Default | Ghost icon, `muted-foreground` glyph, 44px touch target |
| Hover | `foreground` glyph, subtle muted background; Tooltip label |
| Focus | Violet focus ring |
| Absent target | Button not rendered (no dead/disabled control) |

### Contributor chip
| State | Appearance |
|-------|-----------|
| Default | Coloured fill per contributor map, initials in mapped foreground (zinc-50, or zinc-950 for JS/amber) |
| Hover / focus | Tooltip reveals full name |

### Global focus ring
All interactive elements inherit the violet ring token (`--ring` = violet-600) already set in `app/globals.css` (`outline-ring/50` base + component ring). No override needed.
