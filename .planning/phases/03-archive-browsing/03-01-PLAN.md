## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Apple Music API → import route | External catalog data (titles, artists, description text) enters the DB |
| Playlist description text → parser | Untrusted free-text parsed for initials + YouTube URLs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | YOUTUBE_RE against description text | mitigate | Regex captures a bounded 11-char video id and returns only a well-formed youtube.com/youtu.be URL; no eval, no dynamic URL construction from arbitrary substrings |
| T-03-02 | Injection | youtubeUrl stored then rendered as href (Plan 02) | mitigate | Only URLs matching the fixed YOUTUBE_RE (https + known host + id charset) are stored; Plan 02 renders with rel="noopener noreferrer" target="_blank" |
| T-03-03 | Elevation of Privilege | import route trigger | accept | Import trigger is already admin-gated (401/403 from Phase 1 ACCESS-02/03); this plan adds no new write surface |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | Zero new packages this phase (RESEARCH.md: no installs); package legitimacy gate not applicable |
</threat_model>
