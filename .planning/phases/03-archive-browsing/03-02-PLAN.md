<objective>
Deliver the browse vertical slice end-to-end: a user can land on the site, see the full session
archive as a card grid, open any session, and jump out to Apple Music or YouTube per track. This is
the thinnest complete slice that makes BROWSE-01, BROWSE-02, and BROWSE-03 true. The interactive
view toggle (table/timeline) and search come next in Plan 03 — this plan ships the default grid view
and both RSC pages so a real user can browse the archive after it completes.

Purpose: Public read layer over Phase 2 data. Server Components own all Drizzle reads and render
static HTML; a minimal ArchiveClient island renders the grid (it will grow to own the toggle +
search in Plan 03). Contributor identity colours are established here as a shared source of truth
reused by Plan 03 and Phase 4.

Output: `/` redirect, `/sessions` archive grid, `/sessions/[sessionNumber]` detail with track links,
contributor colour map + chip, session card.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public browser → /sessions and /sessions/[n] | Unauthenticated read-only surface; no login, no writes |
| Stored appleId / youtubeUrl → rendered href | DB values become external navigation targets |
| URL path param sessionNumber → Drizzle query | User-controlled numeric route segment |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Information Disclosure | public /sessions pages | mitigate | Queries select only public archive fields (session number, theme, date, description, track metadata, contributor display names) — no user emails, tokens, roles, or account rows joined |
| T-03-05 | Tampering (reverse tabnabbing) | Apple/YouTube external links | mitigate | Every target="_blank" anchor carries rel="noopener noreferrer" (enforced in Task 3 acceptance criteria) |
| T-03-06 | Injection | sessionNumber route param | mitigate | Number.parseInt + Number.isNaN guard → notFound(); value passed only via parameterised Drizzle eq(), never string-concatenated into SQL |
| T-03-07 | Tampering | appleId in deep-link URL | mitigate | URL is `https://music.apple.com/gb/song/${appleId}` with a fixed host/path; appleId originates from the Apple catalog API, not user input; rendered as href only |
| T-03-SC | Tampering | npm installs | accept | Zero new packages this phase; legitimacy gate not applicable |
</threat_model>
